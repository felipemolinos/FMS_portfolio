# Microsoft Fabric — Olist E-commerce

Ingestion and transformation pipeline using Microsoft Fabric
(Lakehouse, Data Factory, integrated Power BI).

## Goal
Demonstrate fluency in the Fabric ecosystem: ingestion, medallion
architecture (bronze/silver/gold), and direct Power BI consumption
without data duplication.

## Structure
- Lakehouse with bronze/silver/gold layers
- Ingestion pipelines for the Olist dataset
- Power BI report connected via DirectLake
